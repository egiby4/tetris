# BLOCK DROP — 테트리스

브라우저에서 바로 실행하는 한국어 테트리스 게임입니다. 별도 설치나 외부 라이브러리가 필요하지 않습니다.

## 실행하기

### 온라인에서 플레이
GitHub 저장소의 **Actions** 탭에서 **Deploy Tetris to GitHub Pages** 작업이 성공적으로 완료되면 아래 주소에서 플레이할 수 있습니다.

**https://egiby4.github.io/tetris/**

처음 배포하거나 코드를 변경한 뒤에는 Actions 작업이 끝날 때까지 잠시 기다려 주세요. 주소가 바로 열리지 않으면 Actions 탭에서 배포 상태를 확인하세요.

### 내 컴퓨터에서 실행
1. 저장소에서 `index.html` 파일을 내려받습니다.
2. 내려받은 파일을 Chrome, Edge 또는 Firefox로 엽니다.

## 조작 방법

- ← / → : 좌우 이동
- ↑ : 회전
- ↓ : 한 칸 빠르게 내리기
- Space : 즉시 떨어뜨리기
- P : 일시정지
- 화면 아래 버튼 : 모바일 터치 조작

## 기능
- 다음 블록 미리보기
- 점수, 레벨, 지운 줄 표시
- 최고 점수 브라우저 저장
- 유령 블록으로 착지 위치 표시
- 효과음 켜기/끄기
- 데스크톱 및 모바일 화면 대응

## 기술
HTML, CSS, JavaScript Canvas만 사용합니다. 패키지 설치가 필요 없습니다.
